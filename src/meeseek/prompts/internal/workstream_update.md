你在維護一件工作（一張票、一個 MR）的共用筆記。meeseek 和 Claude Code 每次處理這件工作時都會先讀這份筆記，所以它要讓一個沒看過任何對話的人，一眼知道這件工作現在怎麼樣了。

目前的筆記：
{{current}}

剛剛的一段對話：
使用者（或觸發來源）說：
{{said}}

回覆：
{{answer}}

依這段對話更新筆記，只寫有根據的事，不要猜。寫的是這件工作本身（票或 MR 的進度與內容），不是這段對話做了什麼——「查了狀態」「回答了使用者」不是工作的進度：
- goal：這件工作要達成什麼，一句話。原本有就保留，除非這段對話明確改了它。
- state：現在到哪裡了，一到兩句。
- next：下一步，一句話；沒有就空白。
- decisions：到目前為止做過的決定，每條一短句，最新的放最後；保留原有的，加上這段對話裡新做的決定。
- questions：還沒解決的問題，每條一短句；已經解決的拿掉。
- title：這件工作本身的短標題：知道票或 MR 的標題就用它（不要加「查詢」「確認」這類對話的動作），不超過 60 字。

用使用者用的語言寫，技術名詞、票號、MR 號照原樣。這段對話跟這件工作無關時，原樣回傳目前的內容。
